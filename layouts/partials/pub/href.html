{{/* Returns a URL safe to put in href/src. Absolute URLs (https://..., mailto:, //cdn...), anchors (#...) and root-relative paths (/...) pass through unchanged. Anything else is a file under static/ (e.g. uploads/x.pdf) and is resolved against the site's base URL so it works from any page, not only the homepage. */}} {{- $u := . | string -}} {{- $out := $u -}} {{- if not (or (findRE `^[a-zA-Z][a-zA-Z0-9+.-]*:` $u) (hasPrefix $u "//") (hasPrefix $u "#") (hasPrefix $u "/")) -}} {{- $out = $u | relURL -}} {{- end -}} {{- return ($out | safeURL) -}}
